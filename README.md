# Calculator

A desktop calculator application built in C with a GTK4 GUI.
Designed using Cambalache UI designer and styled with custom CSS.

## Features
- Basic arithmetic operations (+, -, ×, ÷)
- Percentage calculation
- Chained calculations (multiple numbers)
- Delete and clear functionality
- Dark theme UI

## Platform Support
> **Officially tested on Linux (GNOME). Other Linux desktop environments may work but are not guaranteed.**


- ✅ Linux — GNOME desktop environment
- ⚠️ Linux — Other desktop environments (untested)
- ❌ Windows — not supported
- ❌ macOS — not supported

## Built With
- C
- GTK4
- Cambalache (UI designer)

## How to Build
step 1: Clone the repository
```bash
git clone git@github.com:Niteshkamat11/CALCULATOR.git
```
step 2: Navigate into the project
```bash
cd CALCULATOR
```
step 3 : Build the project
```bash
make
```

## Run
From the root directory:
```bash
./nit-calculator
```


## Project Structure
src/       → C source files
include/   → header files
ui/        → Cambalache UI and CSS files
